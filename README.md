#  Demo API - Spring Boot Mínimo

Este projeto é uma API REST desenvolvida em Java 21 com Spring Boot. Ele foi construído como atividade prática para a configuração e domínio de um Ambiente de Desenvolvimento Java Moderno, utilizando o VS Code como IDE completa.

##  Tecnologias Utilizadas
* **Java 21 LTS** (Adoptium Temurin)
* **Spring Boot** (Web, Data JPA, H2 Database)
* **Visual Studio Code** (IDE)
* **Extensões:** Extension Pack for Java, Spring Boot Tools e REST Client.

##  Como Executar o Projeto (Setup)

1. Certifique-se de ter o **Java 21** instalado. No VS Code, o caminho do JDK deve estar devidamente configurado no arquivo `settings.json`.
2. Abra a pasta raiz do projeto (`demo`) no VS Code.
3. Abra o terminal integrado da IDE e execute o Maven Wrapper com o comando abaixo:

   ```bash
   ./mvnw spring-boot:run
